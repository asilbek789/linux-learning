# Linux Upskill — Day 3  
## OverTheWire Bandit 16–18

### Цель
На практике изучить работу с сетевыми сервисами, SSL, SSH-ключами и ограниченными shell-сессиями.

---

## Bandit 16
**Что делал:**
- Просканировал локальные порты `31000–32000`
- Подключался к сервисам через `openssl s_client`
- Отправлял текущий пароль и анализировал ответы

**Результат:**
- Найден корректный SSL-сервис
- Получен RSA Private Key для следующего уровня

---

## Bandit 17
**Что делал:**
- Сохранил private key в файл
- Выставил корректные права (`chmod 600`)
- Подключился по SSH с использованием ключа

**Результат:**
- Успешный вход без пароля
- Получен пароль для Bandit18

---

## Bandit 18
**Что делал:**
- Обнаружил, что shell закрывается сразу после входа
- Использовал SSH для выполнения одиночной команды без интерактивного shell

**Результат:**
- Прочитан файл с паролем следующего уровня
