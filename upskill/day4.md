## 📅 Upskill Day 4 — Linux Fundamentals (Summary)

### 🔧 Что было изучено:

**1️⃣ Установка и использование mc (Midnight Commander)**

* Установлен файловый менеджер `mc`
* Изучена навигация по файловой системе Linux
* Практика работы с файлами и каталогами в TUI-интерфейсе

**2️⃣ Структура файловой системы Linux**

* Изучены ключевые каталоги:

  * `/home` — домашние каталоги пользователей
  * `/root` — домашний каталог суперпользователя
  * `/etc` — конфигурационные файлы системы
  * `/var/log` — системные логи
  * `/sbin` — системные утилиты администратора

**3️⃣ Файл `/etc/passwd`**

* Понято, что файл **не содержит реальные пароли**
* Символ `x` указывает, что пароли хранятся в `/etc/shadow`
* Файл используется для хранения информации о пользователях

**4️⃣ Конфигурация SSH (`sshd_config`)**

* Найден файл `/etc/ssh/sshd_config`
* Изучено понятие комментариев (`#`)
* Понято, что порт SSH по умолчанию — `22`, если строка `Port` закомментирована

**5️⃣ Анализ логов (`/var/log/auth.log`)**

* Проведён анализ логов аутентификации
* Найдены записи использования `sudo`
* Понято, что логи используются для аудита действий пользователей

**6️⃣ Работа с пакетами (`bsdgames`)**

* Установлен пакет `bsdgames`
* Запущена игра `snake`
* Сделан вывод, что пакет установлен корректно и содержит исполняемые файлы
